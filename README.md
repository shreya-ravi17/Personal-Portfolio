# Personal Portfolio Website

A responsive personal portfolio website showcasing my profile, education, technical skills, projects, achievements, certifications, and contact details.

## 🌐 Live Website

[View Portfolio](https://shreya-ravi-mashelkar-portfolio.netlify.app)

## 🚀 Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript

## ✨ Features

- Responsive navigation bar
- Hero section with profile introduction
- About Me section
- Education details
- Technical skills
- Project showcase
- Experience section
- Achievements & Certifications
- Contact information
- Responsive design for desktop and mobile devices
- Resume viewing/download option
